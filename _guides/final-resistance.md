## About the Table
Final Resistance is a 2023 release by Multimorphic for their P3 modular platform system. Designed by Scott Danesi with rules by Bowen Kerins, this game features a resistance theme with adventure modes, multiball features, and classic alphanumeric-style gameplay reminiscent of late 80s machines.

## Early Game Strategy
Focus on starting adventure modes through the main ramps to build up green stamps, which serve as multipliers for the "Select an Adventure" mode. Hit the left targets to spell LOCK and advance toward Lock and Load multiball. The baseline strategy involves shooting for adventures and working toward getting locks for multiball opportunities.

## Mid Game Strategy
The core scoring strategy revolves around adventure modes and the green stamp multiplier system. Complete adventure modes to earn green stamps, as each green stamp acts as a multiplier for the lucrative Select an Adventure mode. Work on spelling LOCK through the left targets to set up Lock and Load multiball. Intermediate players should focus on incorporating additional features while maintaining adventure mode progression.

## Late Game Strategy
Prioritize completing any started adventure modes for their completion bonuses. If you have collected multiple green stamps, focus on reaching Select an Adventure mode for the multiplied scoring opportunity. Be conservative with multiball management to maximize jackpot collection rather than going for risky shots that could drain balls quickly.

## Multiballs
**Lock and Load Multiball**: Started by spelling LOCK through the left targets above the left flipper. This appears to be the main multiball feature, though specific jackpot values and strategy details were not available in the sources.
